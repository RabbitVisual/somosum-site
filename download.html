Novidades 8.8.32

Segurança e verificação

Confirme que o arquivo é autêntico

O SOMOSUM é distribuído pela Rabbit Visual via GitHub Releases. Por ser um app novo e independente, o Windows SmartScreen pode exibir um aviso na primeira execução — é um falso positivo. Você pode conferir a integridade do arquivo pelo código SHA-256 na página da release.

SOMOSUM-Setup.exe GitHub Releases SHA-256 na release

1. Verifique o hash (opcional)

No PowerShell, rode Get-FileHash .\SOMOSUM-Setup.exe -Algorithm SHA256 e compare com o valor publicado na release setup-8.8.32 no GitHub.

2. Se aparecer o SmartScreen

Clique em “Mais informações” e depois em “Executar assim mesmo”. O aviso some conforme mais igrejas instalam.

3. WebView2

Se faltar, o próprio instalador oferece o link oficial da Microsoft. Sem ele, a projeção continua funcionando.

Antes de instalar

Requisitos mínimos

Confira o PC da igreja. O instalador avisa se o WebView2 estiver ausente.

  • ✓
    Windows 10 ou 11 (64 bits) Arquitetura x64. Não suportamos 32 bits.
  • ✓
    Microsoft Edge WebView2 Runtime Necessário para a interface. Se faltar, o Setup oferece o link oficial: baixar WebView2.
  • ✓
    ~1,5 GB livres no disco O Setup descompacta runtime .NET self-contained e conteúdo.
  • ✓
    Projetor ou 2º monitor (recomendado) Para a Projeção. Stage e Remote usam a rede local da igreja.
  • ✓
    Rede LAN (opcional) Para Remote no celular e Stage em outro PC — sem internet obrigatória.

Depois do download

O que fazer em seguida

Execute o Setup

No Windows SmartScreen, escolha “Mais informações” → “Executar assim mesmo” se aparecer o aviso (arquivo assinado).

Abra o Controle

Monte a ordem do culto, ative Ao vivo e abra a Projeção no monitor do projetor. A prévia espelha o fundo animado.

Leia o guia

Stage, Remote e plugins estão explicados em linguagem simples.

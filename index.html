Finalidade do aplicativo

Para que serve o SOMOSUM?

SOMOSUM é um aplicativo desktop para igrejas. A finalidade principal é projetar o conteúdo do culto na tela (músicas, Bíblia e mídia). Também oferece um recurso opcional de backup no Google Drive: ao entrar com a conta Google, o SOMOSUM pode guardar e restaurar arquivos de backup apenas no Drive do usuário, para proteger os dados da igreja.

  • Projeção do culto

    Mostrar letras, textos bíblicos e mídia para a congregação durante o culto.

  • Operação pela equipe

    Quem opera o computador avança o culto com organização e clareza.

  • Backup opcional no Google Drive

    Com login Google, o SOMOSUM salva cópias de segurança no Drive da igreja — só arquivos criados pelo app.

  • Privacidade

    Os dados do culto ficam no computador; o Drive só é usado se a igreja autorizar. Veja a Política de Privacidade.

App purpose (English): SOMOSUM is a Windows desktop application for churches to project worship content (lyrics, Bible text, and media). It optionally uses Google Sign-In so the church can back up and restore SOMOSUM backup files to the user’s own Google Drive (drive.file scope — only files created by the app).

Por que baixar o SOMOSUM

O culto na tela, com tranquilidade

O aplicativo SOMOSUM coloca na tela o que a congregação precisa ver — enquanto a equipe acompanha o ritmo do culto.

  • Letras das músicas

    Projete hinários e canções para toda a igreja cantar junta.

  • Bíblia na tela

    Mostre o texto bíblico no momento certo, limpo e legível.

  • Vídeos e imagens

    Fundos e mídias para o clima da celebração.

  • Funciona sem internet

    Instala no PC da igreja; o culto segue mesmo offline. O Google só entra no backup opcional.
